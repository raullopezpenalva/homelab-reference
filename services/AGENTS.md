# Service instructions

Read services/README.md and the relevant directory README first. Source folder
names are categorized; logical bundle keys and remote project paths remain
stable through the explicit Ansible mapping. Keep database lifecycle separate
from web/API delivery. Keep sample inputs fictional, real images selected by
digest and actual secrets/inventory outside the public tree. Update operations,
documentation and offline checks together. Do not start/build containers, publish
an image, expose a port or alter a deployed service without an operation request.
